# 完整测试流程
版本：2026-10-11。照着从头走一遍，就把爪记现在的功能都点到了。每一步写的是“做什么 → 应该看到什么”。

测试地址：https://baix827.github.io/-Pawnote/ （电脑和手机浏览器都行，手机更接近真实效果）。
数据只存在当前浏览器里，换浏览器或清缓存就是一只新宠物。想从头再来：爪册 → 设置 → 清空本机数据。

发现不对的地方，记下“第几步、你做了什么、看到了什么”，最好带一张截图。

## 一、第一次进来：登记
1. 打开网址 → 看到“欢迎搬进爪爪镇”的登记页，橘色波普风格（粗黑描边、撞色块）。
2. 不填名字直接点“领取居民证” → 提示要先起名字，不会进去。
3. 填名字，选“猫猫”，年龄填 0 岁 8 个月 → 人生路线自动推荐“校园”。
4. 把年龄改成 2 岁 → 推荐变成“职场”。再手动点“去上学” → 以你选的为准。
5. 性格先点一个标签（比如“傲娇”）；再点“做一次性格问卷”，答完 5 题，查看结果并采用 → 性格栏变成问卷结果，还能手改。
6. 第 6 项选一个称呼（比如“妈妈”），或自己写一个。
7. 第 7 项到家日期填一个过去的日期，如 2024-03-15。再试着填明天的日期 → 保存时应提示日期不对。
8. 加一张头像照片（可选）→ 上方预览卡同步变化。
9. 点“领取居民证” → 进入首页“爪窝”。

想先随便看看，也可以在登记页点“体验橘总的生活”，用示例猫走后面的步骤。

## 二、爪窝（首页）
10. 橘色主角卡上有超大的名字、身份和等级、性格标签、照片，底下一条黑底荧光字在滚动。
11. 主角卡下方的气泡是它最近说的一句话（还没记录时是按时段的问候）。
12. 绿色的“它今天干了啥？”能点进爪语。
13. 地图上三栋房子分别能进爪册、爪迹、爪友圈。
14. 底部黑色导航四个入口加中间的橘色“＋”，都能点。
15. 首页可能出现“测测××的爪格”“××给你写了一封信”“××在喊你”这几种卡片，后面会分别测。

## 三、爪语（记录）：核心功能
16. 点“＋” → 上面是你说话的气泡，下面是它说话的气泡。
17. 在上面写：`今天它把我的水杯推下去了，还一脸无辜` → 不用点任何按钮，下面立刻出现它的第一人称版本，称呼用的是你选的“妈妈”，“一脸无辜”被它换了个说法并加了一句注。
18. 看“这算哪类事” → 自动选中了“拆家”。手动改成别的标签 → 下面的文字跟着变。
19. 依次点四种口吻：内心独白、打工或校园日记、爪友圈动态、爪报 → 每种写法不一样。
20. 点“换个说法” → 当前口吻换一版。
21. 直接改下面气泡里的字 → 出现“主人润色”的标记。再改上面的原话 → 下面重新生成，你的润色被覆盖（这是预期的）。
22. 点“让 AI 来说（用 1 次）” → 等几秒，四种口吻换成 AI 写的，标记变“AI 生成”，本周剩余次数减 1。再点一次用完 2 次 → 按钮变灰。
23. 贴一张照片 → 出现预览，可更换、可移除。
24. 勾选“贴到本机爪友圈”，点“保存日记” → 回到首页，提示 +20 XP。
25. 再记四五条，覆盖不同的事：睡觉、偷吃、洗澡、散步各写一条，其中两三条带照片、两三条勾选爪友圈。后面的功能要用到。
26. 草稿：写到一半不保存，直接去别的页面再回来 → 内容还在。

### 性格是否真的影响文字
27. 爪册 → 编辑档案，把性格改成“亲人” → 回爪语写同一句话，语气应明显变软、老提到你。
28. 再改成“戏精”“稳重”各试一次 → 戏精夸张，稳重像打报告。
29. 在性格里手写“傲娇，有点抽象” → 每条都会多出一句离谱的话。

### 难过的事
30. 写：`它今天生病住院了` → 四种口吻都不开玩笑，没有调侃和报纸腔。
31. 写：`它今天去世了` → 不替它说话，按你的原话保存，页面有一句说明。（测完可以把这条删掉。）

## 四、爪册（档案）
32. 顶部档案卡：名字、物种、年龄、性格、日记数、动态数、路线。
33. “人生日记”时间轴按日期排列，带照片的有小图，贴了爪友圈的有标记。
34. 点任意一条 → 进入“这一天”：上面是你的原话，下面是它说的，可切换四种口吻。
35. 在“这一天”点“删除记录” → 先确认，确认后这条消失，经验减 20。
36. 点“编辑档案” → 改名字或称呼后保存 → 旧日记保持当时的身份，新日记用新的。

## 五、爪迹（成长）
37. 通行证：上班的是员工通行证，上学的是学生通行证，有条形码和等级章。
38. 经验条：每条记录 +20，满 100 升一级。
39. 成长路线三个里程碑：Lv.1 已解锁，Lv.3、Lv.5 是锁着的。
40. 点“看本月工资条和考核”：
    - 上班的：工资条有底薪、各项津贴，拆家是扣款（粉色标出），底下是实发多少小鱼干。
    - 上学的：成绩单六门课，没做过的写“缺考”。
    - 绩效等级章：记录 1 到 3 条是 C，4 条起是 B，10 条起 A，20 条起 S。
    - 考核报告：出勤天数、记录数、最常做的事、本月代表作、你的主管评语、它的自评（自评随性格变）。
41. 在编辑档案里把路线从职场换成校园 → 这里从工资条变成成绩单。

## 六、爪报（报纸）
42. 在任意一条记录里点“制作爪报卡”，或在首页点爪报卡片。
43. 顶部切换四个版式：日报、号外、通缉令、封面 → 每个都能正常显示，没照片时通缉令和封面用头像或物种图案。
44. 点“保存新闻卡” → 下载一个图片文件（网页上是 SVG），用浏览器打开，版式和你选的一致。
45. 打开第 30 步那条“生病住院”的记录的爪报 → 没有版式可选，只有一张朴素的记录卡。

## 七、爪友圈
46. 能看到你勾选过“贴到爪友圈”的动态，以及它自己发的动态。
47. 爪爪镇居民是 App 里的虚拟角色，会给它点爪、留言；页面上有说明它们不是真实用户。
48. “全部 / 只看××”筛选可切换。
49. 试“送回小镇”和“请它回来” → 对应居民的互动消失或恢复。
50. 试删除一条评论、撤回一条动态 → 动态撤回后记录仍在爪册里。
51. “大草坪”显示“即将开放”，点不进去是正常的。

## 八、时光机
52. 爪册 → 时光机：显示“开始记录的第几天”；填过到家日期的还有“来到你身边的第几天”和周年倒数。
53. 成长对比：有两个以上月份带照片的记录时，并排显示最早和最近的一张。（当天测只会有一个月，属正常。）
54. “第一次”：第一条记录、第一张照片、第一次洗澡、偷吃、拆家、散步等，点开能看到当天。
55. 想看周年提示：把到家日期改成去年的今天 → 首页和时光机出现“到家 1 周年”。

## 九、爪约（提醒）
56. 爪册 → 爪约：点一条“它常想做的”加进去，或自己写一件它喜欢的事，设时间和日子。
57. 时间故意填错（如 25:99）→ 提示格式不对。
58. 把时间设成两三分钟后 → 到点打开首页，出现“××在喊你”，可以点“陪了”或“晚点”。
59. 点“陪了” → 问你要不要记进爪语。
60. 网页版不会弹系统通知，只在首页提醒；手机 App 才有通知。这一点是预期的。

## 十、爪格测试
61. 首页的“测测××的爪格”卡片，或爪册里进入 → 8 道题。
62. 答完出一张结果卡 → 可以“设为它的性格”，也可以“分享这张卡”或“重新测一次”。
63. 设为性格后回爪语写一条 → 语气跟着新性格走。

## 十一、爪信
64. 爪册 → 爪信：它按已保存的记录写给你的信，有数字小结、告状、表扬、给你打的分，可以翻页和分享。
65. 记录很少时信会比较短，属正常。

## 十二、设置
66. 右上角齿轮进入。把语言切到 English → 所有页面的界面文字变英文；已保存的故事不变。切回中文。
67. 在英文下进爪语写一句英文 → 它的版本是英文写法（不是中文直译）。
68. “导出全部数据” → 下载一个备份文件。
69. “清空本机数据” → 确认后回到登记页。
70. 在登记页点“从 JSON 备份恢复”，选刚才的备份 → 预览后确认，数据全部回来，照片也在。

## 十三、另外值得看一眼的
71. 手机和电脑各开一次，看排版有没有挤出屏幕或文字被截断。
72. 名字起得很长（比如 10 个字）→ 首页和通行证不会被撑坏。
73. 选一个小众物种（兔子、乌龟、鱼）→ 文字里有这个物种自己的梗，不套猫狗的。
74. 刷新页面 → 所有数据都还在。

## 目前已知、不用报的
- 网页版的 AI 走的是海外线路；每台设备每周 2 次，用完要等下周一。
- 网页版没有系统通知、没有拍照入口（只能选图）。
- 爪友圈的居民和大草坪都还是本机的，没有真实的其他用户。
- 会员订阅、云同步、登录都还没做。
- 真机 App 还没打包，上面的流程目前只在浏览器里验证过。
