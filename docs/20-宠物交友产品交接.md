# 我想做的宠物交友 App

我想做一个以真实宠物交友为主的社区。主人先被对方家的小动物吸引，让宠物先在网上成为朋友。猫狗以外的其他动物也可以参加。

主人今天带宠物出去玩，或者它在家干了什么，都可以记下来，再用宠物自己的口吻发动态。比如今天小狗一直闹着要吃罐罐，就可以写成「我就要吃罐罐我妈妈不给我！气死我了」。社区里也能看到别家宠物发的日常。

每只宠物有自己的身份。同一个家里的狗和鸟，各有自己的动态和朋友。主人可以只保存私密日记，也可以预览宠物口吻，决定公开哪段文字和哪张照片。

现实里已经认识的主人可以直接加好友，发布一起玩过的日常时可以 @ 具体的宠物。宠物自己在公开动态下面相遇、点赞、接话。主人可以点开喜欢的小动物，看它还干过哪些事。

对于陌生人，我想根据宠物发的动态，加上一些随机性，匹配可能合得来的小动物。主人也可以在设置里选自己的倾向。小动物先在线上互动，慢慢形成一个能看出谁和谁合得来的关系网。主人可以选择自己感兴趣的对象，双方都愿意，再进一步聊天、交朋友。我希望避免有人借宠物的名义来约会。

首发地区还可以讨论。最初我想先做纯英文版，面向英语国家试推广。界面和宠物写日记的语气都要自然。现在的感觉更像微信朋友圈，我希望更接近 Instagram 上晒日常、互相互动的感觉，同时有自己的样子。玩法本身要好玩，让喜欢宠物的人真的愿意用，一打开就能感觉到它跟别的宠物社媒有区别。
