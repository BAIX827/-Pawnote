# 小红书宠物号调研：宠物口吻怎么写（2026-10-27）

- 方法：在 Chrome 里用已登录的小红书账号搜 9 个关键词，每个词点开 3–4 篇高赞笔记，看图片里的文字、正文和前几条热评。只读，没有点赞、评论、关注、私信或发布。
- 样本：29 篇笔记。点赞数是 2026-10-27 页面上显示的数字。
- 原句每句不超过 30 字。错别字是原文就有的，属于人设的一部分。
- 用途：给 [13-宠物语气指南](../13-宠物语气指南.md) 和 [15-小动物内心与爪友圈文案](../15-小动物内心与爪友圈文案.md) 当参考，不是要照抄。

## 一眼结论

1. **最火的不是“宠物在说话”，而是“宠物在用人类的 App”。** 微信聊天、朋友圈、论坛帖、搜索记录、短信、亲密付、校长信箱，换一个界面就是一个新系列。读者笑的是用人类格式装宠物逻辑的错位。
2. **固定角色加品种刻板印象，能撑起长期连载。** 诚实一口靠“超级耶耶（萨摩）/ 比格天下第一 / 聪明边边 / 啵恩山（伯恩山）/ 哈哈（哈士奇）”出了 15 期朋友圈，热评都在讨论角色：“小伯脚大所以老打错字”“边牧的短信有标点”。
3. **自称是人设最快的入口。** 拿名字的一个字当自称（“耶决定这辈子都不笑了”），用第三人称“咪”“狗”“小狗”，或者第一句就自我介绍“我是一只小狗，……”。
4. **热评区会接着用宠物口吻写。** 高赞评论常常就是续写，比如“人你死哪去了人——”“请你册掉。——三花妹妹”。这说明格式容易模仿、容易接龙。
5. **好笑和治愈经常在同一篇。** 论坛体先搞笑，结尾才翻出“原来人在找你”；监控时间戳漫画一句台词都没有，靠动作把人看哭。

## 可复用的写法规律（10 条）

> 和 [docs/13 v3](../13-宠物语气指南.md) 不一致的地方，以 docs/13 为准：中文自称默认是咪 / 汪 / 名字，不是“我”；不用本喵 / 本汪；主人称呼仍由主人自己设定。

1. **自称就是人设。** 拿名字里的一个字当自称（耶、oneone），用第三人称（咪、狗、小狗），或者开头先自我介绍（“我是一只小狗，”）。一只宠物选定一种以后全篇不要换。
2. **叫人的方式决定亲疏。** 喊“妈 / 妈妈”最黏，喊“人”比较疏离也比较好笑，喊“主人”最中性，喊“老大”有点小弟的味道。和自称一样，一旦定下就固定。
3. **用宠物的逻辑误读人类行为。** 寻猫启事被当成通缉令，人的手势被当成要给猫条，带去绝育被说成“断情绝爱”。这是最稳定的笑点来源，也很适合“小动物内心”这个功能。
4. **把宠物的生理特点写成语言特点。** 脚大所以打错字，鼻子灵所以“我闻闻”，没有时间概念所以刷屏问“啥时候回来”，不认识东西所以说“红红的 甜甜的 小小的”。这比直接给宠物贴形容词更可信。
5. **套人类的界面和格式。** 聊天、朋友圈、论坛帖、搜索记录、短信、留言板、监控时间戳，同一只宠物换一种格式就是一篇新内容。爪友圈和日记已经有现成的界面可以接。
6. **前后反差，先硬后软。** 先说狠话，再自己拆穿：“耶决定这辈子都不笑了”之后马上被说“别笑”；“不需要人陪”之后接“只是想显得我很厉害”。傲娇和戏精都靠这一招。
7. **标点和重复就是情绪。** 感叹号一串、连发同一句、句尾字重复（“尺尺尺尺”）、波浪号拖长音，适合憨、黏、戏精。冷的性格反过来，用句号和短句。
8. **用括号写旁白和动作。** “（摇尾巴）”“（超特别）”“（狠）”“*把自己扭成陀螺*”，用来补充宠物没说出口的状态，比写一大段描述更轻。
9. **借用人类网络腔，但只借一点。** 论坛腔（如题、楼主、过来咪）、职场词（实习、团建、罚钱）、情感话术（原生家庭、看透你了）。一篇用一个梗就够了，用多了会像在模仿人。
10. **一句台词配一个具体画面就能成立。** 大量高赞笔记只有一张照片加一句话，比如“咳咳 咪平时很忙的”“我才没生气！不信你看镜子”。日记的标题和爪友圈的第一句，应该就是这样一句能单独成立的台词。

另外两条和产品相关的观察：
- **治愈结尾的收藏率更高。** 先好笑再暖，比如通缉令其实是有人在找你，监控画面里狗抱着拖鞋。收藏数明显比纯搞笑的高（妘箖 2465，冥想的角瓜 875）。
- **热评区会主动续写。** 读者喜欢替宠物回一句。这可以对应到 App 里“主人回复 / 宠物再回”的互动。

## 不同性格适合借鉴什么

对应 [13-宠物语气指南](../13-宠物语气指南.md) 里的七种脾气。

| 性格 | 可借鉴的样本 | 具体写法 |
|---|---|---|
| **傲娇（酷）** | 这狗《今天不需要人陪》、grapelu“我才没生气”、诚实一口比格“点赞算你的狗命”、咪真是看透你了 | 先否认在意，再露馅；句子短，用句号；最多带一句“（其实……）”拆穿自己 |
| **黏人（黏）** | 假如小狗会发微信、大厨八号“贴贴妈妈”、鱼蛋“小狗没有你睡不着的”、猫说：我想你 | 刷屏问“啥时候回来”；叠词“贴贴”；主人一回来就“扭成陀螺” |
| **憨** | 诚实一口伯恩山（打错字）、金毛小鸡毛“妈！！！！”、我是一只小狗“我先盖个章”、红肠狗“朋友-1” | 不懂也很开心；感叹号多；把不懂的东西描述出来（“红红的 甜甜的”）；好心办坏事 |
| **戏精（戏）** | 超级耶耶“这辈子都不笑了😡”、拉拉“不管怎样饭还是要吃的”、莓果酸奶碗“太受欢迎了怎么办”、比格“天生皇帝命 / 贱命一条” | 小事演成大事，凡尔赛式自恋；演完被拆穿，或者自己破功 |
| **好奇（奇）** | 布兰德狗勾“搜索记录”、美尼的猫“是要给我猫条的意思吗？”、小猫论坛“咪是被通缉了吗？” | 用提问和推理来写；从猫狗的逻辑误读人类；可以写成“搜索记录 / 求助帖” |
| **淡定（淡）** | 狗狗小学“校长回复”腔、wjm“小猫从来不会说放弃”、咪要进城办点事儿、聪明边边“热闹型 / 嘴硬型” | 像在打报告、写公告；一本正经地说荒唐事；做总结、贴标签；不用感叹号 |
| **胆小（怯）** | 妘箖“监控时间戳”、小猫论坛的老猫劝告“看见人拿着箱子赶紧跑” | 话少，用动作代替台词（“望”“呆呆坐着”）；有安全感的细节，比如闻到人的味道；结尾要暖 |

## 不建议照搬的

- **品牌软广的写法。** 诚实一口在对话里直接写产品名。我们的 App 不应该让宠物替商品说话。
- **骂人和粗口梗。** 这是人类那一方的台词或者图片梗，宠物自己不说。
- **长篇乱码。** 伯恩山式的错字在 App 里常出现会被当成 bug，句库里不用。
- **“人借猫说自己”的打工人梗。** 比如“没班上 / 上着班”。那是人的情绪，不是宠物的内心。
