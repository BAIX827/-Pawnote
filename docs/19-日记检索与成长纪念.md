# 日记检索与成长纪念

## 日记编辑与补记

爪册 → 打开一篇日记 → 编辑日记 → 修改原话、生成表达、类别、照片或实际发生日期 → 保存修改。只改日期、照片或生成文字时，沿用已保存的表达；修改原话或类别会重新生成。保留该日记当时的人设，编辑后经验保持不变。编辑页的修改在保存后生效；返回会保留原记录。新日记的草稿继续自动保存。

爪语上方的实际发生日期支持输入 YYYY-MM-DD 或打开日期选择器。选择器可按月或年翻页，日期最早 1970-01-01，且不晚于今天。新增补记仍计 20 XP，按发生日期放回时间轴，并计入对应月份的月报、爪信、年鉴和成长照片。旧记录补上照片后也会更新时光机的成长对比。

## 搜索与日历

爪册 → 搜索日记，可以匹配主人的原话与四种表达中的标题和正文；多词搜索要求各词都出现。分类、有照片、月份和日历日期可以组合使用。日历从周一开始，显示当前搜索及分类/照片筛选下的日记数量；点某一天看当天记录，再点同一天取消日期选择。点“补记这一天”进入预填日期的爪语。重置筛选回到全部日记；较长列表分批显示。

## 那年今天

首页在存在往年同月同日的日记或声音时显示“那年今天”。可以切换多段回忆、打开原日记、回听原声音。旁白采用本机文案，原事实来自保存的记录。生病、受伤、走失等记录采用平静的回看文字。2 月 29 日的旧记录只在闰年的同一天出现。

## 成长纪念册

爪册或时光机 → 成长纪念册 → 修改标题、选择年份、勾选日记与声音 → 预览 → 导出完整纪念册。全选和清除只作用于当前年份；“全部年份”涵盖全部内容。至少选一篇日记或一段声音才能导出。

导出为单个 HTML 文件，照片与完整声音内嵌，文件可离线保存。用浏览器打开可阅读和回听，顶部“打印 / 保存为 PDF”通过浏览器打印菜单输出纸质或 PDF 版本。纸质/PDF 保留声音日期、标题和备注；回听需要原 HTML 文件。文件包含选中的私密日记，导出前可按内容取消勾选。

Web 下载 HTML；App 打开系统分享，可保存到文件。使用与声音相册相同的媒体资料，不依赖云端图片或声音地址。

## 生日与到家纪念日

编辑宠物档案 → 填写可选生日和到家日期 → 爪册或时光机 → 生日与纪念日。可切换生日/到家纪念日和年份，预览与分享包含照片和宠物口吻信的纪念卡；当天和过去的纪念日可直接进入补记。首页在未来 7 天内有纪念日时展示入口。

信统计前一纪念日起到所选纪念日的已保存记录，引用一条实际原话，并按性格写愿望。难过的记录使用平静语气；最新记录写到去世时采用主人视角纪念页，并暂停首页庆祝卡。2 月 29 日的生日/到家日在平年按 2 月 28 日纪念。生日录入独立于原有年龄字段，不覆盖主人填写的年龄。

Web 分享 SVG；App 分享完整卡片 PNG。照片加载完成后开放分享。

## 数据兼容

新增可选 `Pet.birthDate`，以及 `LifeEvent.occurredOn/savedAt/editedAt` 和 `Draft.occurredOn`。保留 schemaVersion 1，旧备份继续恢复。`occurredOn` 保存实际发生的日历日期，跨时区恢复时以该字段显示和统计；旧记录沿用 createdAt。`savedAt` 保留首次保存时间，`editedAt` 标记最后修改时间。编辑旧记录保留同时正在写的新日记草稿。
