# 决策与待确认事项
版本：0.1 · 2026-10-10

## 已依据用户目标采用的决策
- 产品沿用《毛孩营业中》，模拟人生 + 社交娱乐。
- 最终目标手机 App；先用 Expo 通用工程做 Web 交互原型。
- 首版单宠物、私密记录、本机模板；真实社交与云端是后续阶段。
- 一条真实事件为统一数据源；规则管理成长，生成器处理表达。
- 相机和手机系统体验在 M2 尽早进入真机验证。
- 用户已确认：iPhone 优先，随后 Android；中国大陆首发。

## 暂定假设（开发可继续）
- 中文界面，猫狗优先，校园与职场均可选。
- iOS 和 Android 都属于目标平台；iPad 适配安排在后续阶段。
- 单宠物原型，尚未需要付费功能。
- 初期熟人圈，无默认公开的宠物照片。

## 后续会影响实施的选择
- iPhone 型号、iOS 版本、Apple Developer 会员及 Expo 账号状态；影响设备安装与签名。
- 账号方式：推荐手机号验证码，云端阶段确认供应商、预算与恢复规则。
- 成本预算：云服务、模型和图片存储；服务接入前定额。
- 社交关系：主人级好友与宠物级互动；首版推荐主人级授权、宠物身份展示。

## 风险和处理
1. 社交冷启动：单宠物记录和成长先提供完整体验，真实好友能力随后验证。
2. 四份文案重复：同源记录、风格切换、只发布选中的表达。
3. 成长刷分：原型按唯一事件 +20；正式服务增加重复与频次策略，规则需要产品确认。
4. 本机图片占用：压缩、限制大小、显式备份；正式版对象存储。
5. 拟人故事失真：保留真实描述与生成标识；生成不能改变真实健康/身份事实。
6. Web 通过但手机异常：早期做 native bundle 与真机权限/键盘检查。
7. 上市规则：贴文中的政策和竞品信息作为背景材料；正式发布前按照目标市场重新核对官方来源。

文档里的架构选择是当前建议与实现基线；商业定位和账号体验仍需要真实反馈；平台优先级与首发市场已由用户确认。
