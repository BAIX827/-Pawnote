# 测试与验收
版本：0.1 · 2026-10-10

## 自动验证（v0.1）
- TypeScript 编译检查。
- 备份往返：照片、私密状态、历史人设与草稿保留；损坏、过大、未知版本、重复事件、外部图片 URL 拦截。
- 领域规则测试：第一次保存经验、同 ID 重复保存、删除经验回滚、等级边界、风格切换成长不变。
- 模板生成：原始描述必须保留；宠物人设与路线进入输出；其他标签避免虚构具体真实行为。
- 卡片导出：XML 特殊字符转义，正文换行，虚构娱乐与模板标识。
- Expo Web 静态导出；native bundle 导出提供打包层面的检查。

## 浏览器手动 / 自动旅程
1. 空账号创建猫宠物，选择职场与性格，进入首页。
2. 描述“今天把水杯推下去了”，生成并切换四种风格，编辑文本。
3. 私密保存后检查 20 XP，毛圈为空。
4. 第二条主动勾选本机发布；毛圈显示本人动态，XP=40。
5. 刷新后记录和人设仍在。
6. 打开喵闻并导出卡片，检查来源、日期和虚构标识。
7. 删除一条记录，XP=20，关联本机动态移除。
8. 改为校园路线，检查旧故事身份快照保留，新故事使用校园口吻。
9. 360px 宽度检查导航、编辑器滚动和按钮可访问性。
10. 上传照片、更换、移除；照片刷新后可见。
11. 导出 JSON，检查包括本人档案和记录。
12. 清空取消不影响数据；确认清空后回到初次创建页。
13. 导入无效备份有提示；导入有效备份有预览，取消保留原记录；空档案恢复并刷新后保留照片、记录和私密状态。

未实际执行的项目在交付状态明确标“待验证”。

## 联机与移动发布门槛
- 越权：账号 A 不能读取/修改 B 的私密事件和照片。
- 幂等：重试不会重复事件、经验和发帖。
- 审核：未通过内容无法进入好友列表；举报/屏蔽有效。
- 删除：账号与事件删除能传播到动态、图片、评论及衍生刊物。
- iOS / Android 真机：相册/相机权限拒绝、键盘、安全区域、系统分享、重启持久化。
- 弱网：保存结果明确，重试可恢复；AI 失败回退且无后台擅自发布。
- 运行设备、OS 版本、构建 ID、问题及处理结果记录到发布验收文件。

## Definition of Done
功能符合 PRD，相关规则有验证，数据错误有恢复提示，移动与 Web 的实现范围清楚，文档同步，核心流程未被新改动破坏。


## 档案扩展验收
- 旧 v1 猫狗档案可读取；11 种类型的新档案可生成文案、导出并恢复。
- 其他类型空名称拦截，类型名最多 20 字；性格空内容拦截、最多 60 字。
- 问卷缺答/少于三道明确观察给出提示；作答结果稳定，采用后可改写；保存并刷新后采用的回答保留。
- 猫狗 0/11 个月为校园推荐、12 个月起为职场；未知年龄可手选；其他物种直接手选。
- 年龄非法输入、月数 12、负数、小数和大于 100 岁拦截；手选后修改年龄保留路线。
- 编辑物种/性格/年龄/路线后新故事使用新档案，旧事件快照保持原值；换档案增加 0 XP。
- 390px 手机宽度的类型标签、年龄字段、性格问卷和主要按钮可滚动访问。
