# 海外 App Store 上架清单
版本：2026-10-11。目标：先在海外 App Store 上架爪记 / Pawnote。本清单区分“只能由你本人办”和“可以交给开发来做”。价格、审核时长等会变的信息以 Apple 官方页面为准，办理时再核对。

## 一、只能由你本人办
1. Apple Developer Program 账号：用你的 Apple ID 注册，个人或公司主体二选一，需年费和身份验证。个人主体在商店里显示你的姓名，公司主体显示公司名并需要邓白氏编码。
2. Cloudflare 账号：免费注册。部署网关时需要你在浏览器里点一次授权。
3. 协议与税务：在 App Store Connect 里同意最新协议；做付费订阅前要填好收款银行与税务信息。
4. 决定这些事项（见第三节）并告诉开发：上架地区、是否首发就带订阅、定价、对外联系邮箱。
5. 隐私政策和支持页面的最终内容由你确认，因为它们以你的名义对外承诺。

## 二、可以交给开发来做（账号就绪后）
- 正式的 bundle identifier（现在是开发用的 com.baricy.pawlife.dev）、版本号、图标与启动图。
- 用 EAS 打包、签名、上传到 App Store Connect，先发 TestFlight 内测。
- 商店素材：各尺寸截图、中英文名称、副标题、描述、关键词。
- 隐私政策与支持页面的草稿和托管（可放在现有 GitHub Pages 上）。
- App Store Connect 里的“App 隐私”问卷草稿、年龄分级问卷草稿。
- 订阅接入：商品配置、购买与恢复购买、服务端校验，把“会员不限次数”接到真实订阅上。
- 审核备注：说明 AI 生成内容的用途与标识方式。

## 三、上架前必须定下来的事
- AI 与审核：App 里有 AI 生成的文字。需要有举报或反馈入口、对生成内容的过滤，并在隐私政策里写明主人输入的文字会发给哪家模型服务商。
- 首发是否带订阅：不带则首发更快，AI 先按每周免费次数提供；带订阅则要先完成内购接入与税务信息。
- 爪友圈目前只在本机，不是真实社交。首发保持这样可以避开用户生成内容的审核要求；做成真实社交时需要举报、屏蔽、内容审核与使用条款。
- 数据：记录与照片只存在手机本机。隐私问卷据此填写；若以后做云同步需更新。
- 通知：爪约提醒使用本机通知，需要在首次使用时说明用途。
- 名称：确认 “Pawnote” 在目标地区的商店里没有重名或商标冲突。
- 支持的语言：英文与简体中文；首发地区决定截图和描述要准备哪几种语言。

## 四、建议的顺序
1. 部署网关到 Cloudflare，网页版和测试包先用上 AI。
2. 注册开发者账号（审核通过需要时间，尽早开始）。
3. 开发侧完成正式标识、隐私政策草稿、举报入口、商店素材。
4. TestFlight 内测一轮，收集问题。
5. 提交审核。订阅可放在第二个版本。
