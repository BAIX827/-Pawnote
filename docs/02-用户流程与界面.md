# 用户流程与界面
版本：0.1 · 2026-10-10

## 导航
首页「今日营业」：宠物近况、记录入口、最新日记、个人喵闻。
人生：校园/职场身份卡、经验和成长档案。
爪友圈（原毛圈）：只有小动物说话。自家宠物保存记录时自己起草动态（默认留在窝里），7 位爪爪镇居民发自己的动态、来点爪评论，宠物每天自己逛两次并留言；顶部是好朋狗一排和“今天逛了哪里”，另有“大草坪”页（联机前显示即将开放）。主人不能发帖或评论，见 PRD 8.20。
档案：人设编辑、记录时间轴、数据导出和清空。
全局「记录今天」入口打开编辑器；手机底部四个导航，宽屏显示侧栏。

## 初次使用
展示产品一句话 → 填名字与宠物类型 → 可选年龄 → 选性格标签/直接描述/5 题观察问卷 → 猫狗按年龄推荐或主人手选校园/职场 → 可选头像 → 领取身份卡 → 进入今日营业。
允许先探索示例：显式选择“体验示例”，示例带标签，创建本人宠物时示例记录被替换。
默认首次账号为空；示例数据与本人记录分开。

## 记录编辑器
1. 输入发生了什么；标签为睡觉、偷吃、洗澡、拆家、散步、其他。
2. 可选添加一张照片，照片可更换或移除。
3. 点击生成，出现一份可编辑文本。
4. 日记 / 上学或打工 / 毛圈 / 喵闻标签切换同一事件的表达。
5. 编辑后选择“同步到本机毛圈预览”；默认关闭。
6. 保存，显示 +20 XP，回到首页；完整事件可在档案访问。

用户更改原始描述、事件类型或宠物人设后，旧生成结果作废，提示重新生成。主动重生成替换当前风格，其他已编辑风格保留。

## 新闻
打开本人已保存事件 → 阅读趣味报道 → Web / Mac 保存 PNG 新闻卡，支持的平台可打开系统图片分享 / 移动端分享完整 PNG 卡片。
卡片包含宠物名、照片（若有）、标题、正文、记录日期、模板生成和虚构娱乐标识。
PNG 已在 iOS Expo Go 验证；带照片全卡、真机相册保存与权限仍需设备验收。

## 状态与异常
- 空列表：说明如何添加第一条记录。
- 未生成：保存按钮提示先生成；描述为空无法生成。
- 存储加载：显示加载状态；读取损坏不自动覆盖，允许导出原始数据并选择重置。
- 存储写入失败：保留当前内存版本，提示“本机空间不足，先导出备份”；错误只在成功写入后清除。
- 清空：需要再次确认；删除单条记录也需要确认。
- 图片读取失败/过大：提示原因，文本草稿保留。
- 网络：v0.1 生成和记录使用本机规则与存储；首次网页加载和发布预览仍依赖服务可达。

## 视觉规范
暖白底、橘色主操作、墨绿辅助、真实宠物照片与简洁身份印章。网页大屏留白、卡片层次清楚；手机保留相同功能。正文至少 14px，点触目标优先 ≥44px；按钮有文本与无障碍标签，状态不能只用颜色传达。


## 扩展档案流程（2026-10-11）
其他类型必须填写宠物类型名。问卷允许不确定回答；查看结果前检查全部作答和至少三题明确观察。结果经“采用这个性格”填入描述，主人可继续修改。收起再打开保留本次页面的作答；返回离开页面以已保存档案为准。
猫狗新档案默认按年龄推荐，年龄未填时可改为手选；其他物种直接手选。手选之后修改年龄保留选择，主人可主动恢复按年龄推荐。档案和身份卡展示物种、性格与填报年龄，历史日记保留旧身份。


## 2026-10-11 更新：记录流程与语言
记录页（宠语翻译机）的顺序：主人原话气泡 → 宠物版本气泡（实时出现，可改字）→ 换口吻 / 换个说法 → “让 AI 来说”与本周剩余次数（仅配置网关后出现）→ 标签（自动判断，可改）→ 照片 → 是否贴到本机毛圈 → 保存。
登记页新增第 6 项“它在日记里怎么称呼你”。手账页“数据与备份”上方新增语言切换。
界面语言默认跟随设备，可手动切换；视觉为橘色波普，细则见 12。

## 2026-10-11 爪格测试与爪信
- 爪格：爪册“爪格测试”或爪窝小卡 → 8 道题逐题作答（可返回上一题）→ 结果卡 → 设为它的性格 / 分享 / 重测。测过后爪册显示爪格名。
- 爪信：爪窝“新信”卡或爪册“爪信” → 默认上周的周信，可切到月信、年信 → 点一下翻页（封面、数字、本期之最、告状与表扬、落款）→ 落款页分享汇总卡。打开周信即记为已读，爪窝新信卡消失。App 在爪信页可开关周一收信提醒。

## 2026-10-13 更新：可选资料与日常动线

保留首次登记流程。猫狗默认按年龄自动匹配身份：不足 12 个月为校园，满 12 个月为职场；主人可手动修改，后续改年龄保留手选身份。年龄可填估计值或留空；真实生日已填且年龄留空时按生日计算月龄。年龄和生日均未知时暂用职场身份，仍可直接完成登记。其他物种保留手选。

生日和到家日期均可留空。真实生日优先；仅填到家日期时，默认在到家日生成生日祝福卡与信。卡片标注“用到家日庆生”，年数展示为相伴年数。真实生日字段保持空值，到家日用于庆祝，与年龄计算分开。关闭此偏好后仍保留到家纪念日；后来填写真实生日时自动优先使用生日。

记录顺序调整为照片 → 日期摘要 → 主人原话 → 宠物表达 → 保存。新日记默认从四种口吻随机选择一种，输入、草稿恢复和保存期间保持选中口吻，移除换个说法。日期、分类与本机动态选项折叠。关闭随机后，新日记默认内心独白，主人可手选口吻；已有草稿和历史记录保持原选择。编辑历史记录可手选。主人润色后改原话或分类时，保留已编辑表达，确认保留或按新原话更新后再保存。

首页缩小主角海报，记录入口前置，最近日记放在小镇和成长模块之前。首页的小镇、XP 和爪报默认收起，可在设置开启。爪册只有日记、照片筛选和“成长纪念册”三个入口；成长纪念册按分类收纳声音、纪念日、历史爪信、爪格和年度纪念册，并展示到家天数、那年今天、成长对比和“第一次”。爪信到点在爪窝自动打开，爪约在设置里管理（docs/01 8.29）。日记、爪报、声音、纪念日、纪念册和时光机返回原进入位置，无历史时使用首页或爪册作为兜底。底部加号带“记录”文字。

设置增加“按你的习惯”：用到家日庆生、新日记随机口吻、首页小镇与成长。偏好随本机数据保存和备份恢复，旧备份采用默认值。后续可选行为统一在此扩展。爪友圈保留入口，页首明确说明本机小镇与虚构居民，大草坪入口注明即将开放。

本轮验收：64 项规则测试、TypeScript、ESLint 和 Web 导出通过。因 iCloud 目录读取依赖较慢，浏览器与构建验收使用相同 package-lock 的临时副本。390×844 浏览器验证未知年龄及生日登记、年龄自动匹配及手选保留、到家日生日卡、润色确认与保存、返回首页、偏好刷新恢复、关闭随机后的手选口吻和爪册工具布局；页面无 console error。真机键盘、照片权限和触摸体验仍需设备验收，现有安装版需要重新打包或更新。

## 2026-10-30 导航重排（docs/01 8.37）

底栏：爪窝 / 爪册 / 记录 / 爪友圈 / 我的；桌面侧栏同序。每个功能只有一个“家”，最多点两下到达：

| 功能 | 怎么进 |
| --- | --- |
| 日记、照片、声音、爪信、纪念（纪念日、年度纪念册、成长里程碑） | 爪册顶部标签 |
| 爪格、爪迹、爪约、本月生活回顾、设置 | 我的 |
| 关系网 | 爪友圈顶部；我的 |
| 爪报 | 每条日记上的“制作爪报”；日记详情 |
| 切换 / 添加宠物 | 顶部头像；我的 → 我家的毛孩子 |

爪窝：主角卡 → 它说的话 → 记录按钮 → 本月小结 → 今日便签（爪约 > 纪念日 > 新信 / 爪格，只显示一张）→ 最近发生 → 那年今天。子页面打开时底栏高亮它所属的那一格。
