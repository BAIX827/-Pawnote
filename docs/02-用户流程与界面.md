# 用户流程与界面
版本：0.1 · 2026-10-10

## 导航
首页「今日营业」：宠物近况、记录入口、最新日记、个人喵闻。
人生：校园/职场身份卡、经验和成长档案。
毛圈：本人主动发布的本机动态；联机阶段接好友动态。
档案：人设编辑、记录时间轴、数据导出和清空。
全局「记录今天」入口打开编辑器；手机底部四个导航，宽屏显示侧栏。

## 初次使用
展示产品一句话 → 填名字与宠物类型 → 可选年龄 → 选性格标签/直接描述/5 题观察问卷 → 猫狗按年龄推荐或主人手选校园/职场 → 可选头像 → 领取身份卡 → 进入今日营业。
允许先探索示例：显式选择“体验示例”，示例带标签，创建本人宠物时示例记录被替换。
默认首次账号为空；示例数据与本人记录分开。

## 记录编辑器
1. 输入发生了什么；标签为睡觉、偷吃、洗澡、拆家、散步、其他。
2. 可选添加一张照片，照片可更换或移除。
3. 点击生成，出现一份可编辑文本。
4. 日记 / 上学或打工 / 毛圈 / 喵闻标签切换同一事件的表达。
5. 编辑后选择“同步到本机毛圈预览”；默认关闭。
6. 保存，显示 +20 XP，回到首页；完整事件可在档案访问。

用户更改原始描述、事件类型或宠物人设后，旧生成结果作废，提示重新生成。主动重生成替换当前风格，其他已编辑风格保留。

## 新闻
打开本人已保存事件 → 阅读趣味报道 → Web 保存 SVG 新闻卡 / 移动端分享完整 PNG 卡片。
卡片包含宠物名、照片（若有）、标题、正文、记录日期、模板生成和虚构娱乐标识。
PNG 已在 iOS Expo Go 验证；带照片全卡、真机相册保存与权限仍需设备验收。

## 状态与异常
- 空列表：说明如何添加第一条记录。
- 未生成：保存按钮提示先生成；描述为空无法生成。
- 存储加载：显示加载状态；读取损坏不自动覆盖，允许导出原始数据并选择重置。
- 存储写入失败：保留当前内存版本，提示“本机空间不足，先导出备份”；错误只在成功写入后清除。
- 清空：需要再次确认；删除单条记录也需要确认。
- 图片读取失败/过大：提示原因，文本草稿保留。
- 网络：v0.1 生成和记录使用本机规则与存储；首次网页加载和发布预览仍依赖服务可达。

## 视觉规范
暖白底、橘色主操作、墨绿辅助、真实宠物照片与简洁身份印章。网页大屏留白、卡片层次清楚；手机保留相同功能。正文至少 14px，点触目标优先 ≥44px；按钮有文本与无障碍标签，状态不能只用颜色传达。


## 扩展档案流程（2026-10-11）
其他类型必须填写宠物类型名。问卷允许不确定回答；查看结果前检查全部作答和至少三题明确观察。结果经“采用这个性格”填入描述，主人可继续修改。收起再打开保留本次页面的作答；返回离开页面以已保存档案为准。
猫狗新档案默认按年龄推荐，年龄未填时可改为手选；其他物种直接手选。手选之后修改年龄保留选择，主人可主动恢复按年龄推荐。档案和身份卡展示物种、性格与填报年龄，历史日记保留旧身份。


## 2026-10-11 更新：记录流程与语言
记录页（宠语翻译机）的顺序：主人原话气泡 → 宠物版本气泡（实时出现，可改字）→ 换口吻 / 换个说法 → “让 AI 来说”与本周剩余次数（仅配置网关后出现）→ 标签（自动判断，可改）→ 照片 → 是否贴到本机毛圈 → 保存。
登记页新增第 6 项“它在日记里怎么称呼你”。手账页“数据与备份”上方新增语言切换。
界面语言默认跟随设备，可手动切换；视觉为水彩绘本风，细则见 12。
