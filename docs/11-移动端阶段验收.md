# 移动端阶段验收
2026-10-11 · v0.1

## 环境与范围
Expo SDK 57 / React Native 0.86.3，官方 Expo Go SDK 57，Xcode 27.0，iPhone 18 Pro 模拟器 / iOS 27.0。用户目标设备为 iPhone 17 Pro，本轮未向实体手机安装项目。该轮覆盖业务界面与 Expo Go 已包含的原生模块。

## 已执行
- 创建“测试糯米”猫猫，傲娇人格，职场路线。
- 记录“今天在窗边看雨，最后趴在我的拖鞋上睡着了。”，生成四种表达；编辑日记后切换风格再返回，编辑文本保留。
- 私密保存后档案显示 1 条记录；重新加载后保持 1 条记录、20 / 100 XP。
- 新闻卡导出实际 PNG（约 202 KB），完整标题、正文、来源、虚构娱乐标识可见，打开系统分享后取消回到页面。当前 PNG 样本为纯文字记录。
- JSON 系统分享 → 保存到文件；实际保存文件解析后包含 1 条私密记录和主人编辑标识，日记编辑文本完整。临时缓存文件在面板关闭后清理。
- 选择刚保存的 JSON，显示“测试糯米 · 1 条记录”恢复预览；取消后当前记录保留。
- Web 端执行有效 JSON 实际恢复、错误 JSON 拒绝、恢复取消、刷新持久化、照片保留与导出文件内容一致检查。
- 9 项领域测试通过，包含照片/历史身份/草稿备份往返与错误版本、重复事件、非法照片地址、损坏/超限文件拒绝。

本机证据位于被 Git 忽略的 artifacts：ios-news-card.png、ios-test-backup.json。样本均为本轮测试数据。

## 构建阻塞
本机生成 iOS 工程并安装 CocoaPods 1.17；独立 Release 构建的 React Native 预编译归档下载持续缓慢，已终止该次构建。业务 Hermes bundle 可导出，但当前没有独立 .app 或真机 IPA。后续需要完成依赖下载、重新构建，再配置 Personal Team 签名或验证 xtool 安装。

## 尚待设备验收
- 实体 iPhone 相机、相册权限允许/拒绝与高分辨率图片；带照片的 PNG 全卡分享。
- 500 字描述、2000 字故事、键盘交互、长内容排版与字体放大。
- 独立 App 冷启动、设备重启后的持久化；替换恢复与存储写入失败的原生端行为。
- 超限备份的原生文件选择与内存表现；删除提交和 XP 回滚的设备端流程。
- 实体手机签名安装、xtool 对该 IPA 的兼容性、Android 设备适配。
- 当前首屏身份等级徽章在窄屏可能出现换行，需在实际字体缩放设置下继续检查。

真实账号、跨设备同步、AI 服务和好友社区属于后续开发阶段。
