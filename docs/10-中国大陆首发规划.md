# 中国大陆首发规划
2026-10-10 · 用户已确认中国大陆为首发市场。

## 当前建议
- 平台：先 iPhone 开发包与小范围测试，再 Android。
- 账号：联机 MVP 优先手机号验证码；保留先体验再登录的路径。微信登录作为后续选项，需平台资料和原生能力验证。
- 云端：优先评估国内区域的 TypeScript HTTP API、PostgreSQL 和对象存储，腾讯云作为首个候选。服务开通前确认主体、预算、区域和恢复方案。
- 图片：正式版存对象存储，私密图片由有权用户获得限时访问地址。
- 生成：国内可用模型通过服务端 adapter 接入；模板保留为回退。模型负责表达，事件事实、经验和权限由服务端规则控制。
- 分享：先做手机图片卡保存与系统分享，再评估微信 SDK；以真实用户手机上的分享结果验收。

开发预览的 Sites 地址用于内部展示。正式用户的登录、API、图片和生成链路应在中国大陆的真实网络上验证响应、可达性和失败恢复。

## 联机开发的先后顺序
1. 确认国内云账号及预算；先在开发环境建立 API、数据库、图片存储。
2. 接账号与会话，完成事件保存/删除事务和私密资源鉴权。
3. 图片上传、内容审核、模板/模型生成、失败回退与限流。
4. 真实好友、主人确认发帖、举报和屏蔽。
5. 手机国内网络封闭测试，处理弱网和设备兼容问题。
6. 主体与应用资料确定后完成发布材料和商店审核。

## 发布前需落实的事项
- 按工信部 APP 备案通知核对备案流程、接入服务商及主体材料。
- 隐私披露对应实际使用的 SDK、手机号、照片和记录；先说明用途，再取得适用授权。
- 提供账号删除与数据删除流程，验证动态、照片和衍生内容的移除。
- 内容审核、举报响应与管理员处理形成可执行流程。
- AI 接入时依据实际生成和分享场景核对标识要求。

产品供应商与具体账号方案仍为开发建议；当前尚未开通付费服务、购买短信或部署正式用户后端。
