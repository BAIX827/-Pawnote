# 声音相册

## 使用

从「爪册 → 声音相册」或「时光机 → 打开声音相册」进入，页面沿用现有颜色、标题字体、粗黑描边、硬阴影和贴纸。

直接录音：点「直接录音」→「开始录音」→允许麦克风→「停止录音」→试听、填写标题和备注→「保存这一声」。最长 60 秒，到时自动停止；应用转入后台时停止录音并进入待保存状态。离开页面前需保存片段。

视频提取：点「从视频提取」→选择 5 分钟 / 100 MB 以内的视频→填写开始秒数和片段时长（0.5–60 秒）→提取→试听→填写声音日期和当时月龄→保存。旧视频可填拍摄日期；月龄按档案的年龄记录时间推算，也可以填写或留空。保存后更改档案年龄会保留声音原来的月龄。

阶段是相册分组：幼年、少年、成年、熟龄、待标记。默认按月龄 0–5、6–11、12–83、84+ 预填，主人可调整。声音按日期排列，可筛选阶段、分别回听并确认删除。

视频提取在本机处理，保留片段内的宠物叫声、人声与环境音。支持格式取决于系统解码器；手机建议使用带 AAC 音轨的 MP4 / MOV。Web 录音和视频提取使用 Web Audio 解码并保存 16 kHz 单声道 WAV，方便备份带到手机后回听。iOS 提取 M4A，Android 从 AAC 音轨复制选定片段到 M4A。

## 运行

项目使用 Expo SDK 57，新增 `expo-audio` 和本地 Expo module `modules/paw-audio`。原生模块由 Expo autolinking 接入，原生工程由 Expo 生成。

手机端完整功能使用开发安装包：`npm run build:ios:development`（EAS）或 `npm run ios:device`（已配置本机签名）。模拟器运行 `npm run ios:simulator`。Expo Go 可使用直接录音；视频入口提示需要新版开发安装包。

Web 用 `npm run web`；麦克风需要 HTTPS 或 localhost，首次使用需允许权限。Mac 用 `npm run build:mac` 生成新安装包，打包器包含麦克风用途说明，WebKit 由系统请求麦克风授权。拒绝权限后可到系统设置重新允许。

本机 iPhone 编译遇到 `resource fork, Finder information, or similar detritus not allowed` 时，将项目副本放到 iCloud 之外的本机目录后重新构建，或使用 EAS。

项目已通过 `expo-build-properties` 的 `ios.enableSceneSupport: true` 启用 SDK 57 的场景生命周期兼容配置，支持 Xcode 27 / iOS 27 的启动要求；原生工程由 prebuild 生成。依据 [Expo SDK 57 的 iOS 场景迁移说明](https://github.com/expo/fyi/blob/main/ios-scene-lifecycle.md#staying-on-sdk-57-with-xcode-27)。

## 保存与备份

移动端音频保存在应用文档目录 `paw-sounds`，Web / Mac 保存在 `pawnote-media` IndexedDB。AsyncStorage / localStorage 只保存引用和元数据，读取时还原完整音频。音频先写入，再提交元数据；保存失败时保留旧数据。删除、清空或恢复成功后清理失去引用的声音文件。

设置页导出 JSON 会包含完整音频，恢复预览展示声音数量。相册最多 100 段，每段音频 2 MB；编码后的声音总量最多 12 MB，并受现有 20 MB 总备份限制。旧版本没有 `sounds` 字段的备份继续有效。

## 验收

自动规则覆盖日期和历史月龄、阶段边界、非法片段和元数据、容量限制、备份音频往返、旧备份兼容和英文覆盖。

浏览器流程使用合成麦克风和含音轨的合成视频，验证实际录音、播放、刷新后的 IndexedDB 读取、选取片段、WAV 时长与非静音采样、月龄、删除、JSON 导出、全新浏览器环境恢复、拒绝麦克风授权与 60 秒自动停止；手机宽度截图保存在 `artifacts/sounds/voice-album-mobile.png`。iPhone 17 / iOS 27 模拟器 Release 构建与 Expo 环境检查 21/21 通过。

真机还需验收麦克风允许/拒绝、录音中断、60 秒自动停止、相册取消、iCloud 视频下载、无音轨/不支持编码的视频、后台停止、备份恢复后重启回听和系统存储空间不足。Android 真机需使用包含原生模块的安装包。
