# 视觉与文案规范

版本：2026-10-11，适用于 Web 与移动端共享页面。

## 视觉方向

2026-10-11 用户确认：柔和治愈的水彩绘本风。奶油底色上叠加水彩晕染色块，圆体标题，大圆角卡片配柔和的暖色投影，不使用粗黑描边。点缀元素为胶带、圆形印章、拍立得相框和对话气泡，可有轻微倾斜和缓慢摇摆。

基础色：背景 #FBF5EC；纸面 #FFFDF9；文字 #5A493F；次要文字 #A59486；操作珊瑚 #F2958A；描边 #EBDCC8；职场 #7DB89E / #DCEEDA；校园 #A99CDA / #EDE7F8；暖黄 #FBE6A6；粉 #F9D3DB；天蓝 #D3E8F4。统一 token 保存在 src/components/ui.tsx。标题用系统圆体（iOS 为 Yuanti SC），不额外打包字体。图标沿用 Feather，Web 使用内嵌 SVG。

## 页面布局

- 街区：宠物主角卡、三个可点击建筑、成长存折、个人喵闻、最近记录。展示真实本机记录数量和经验。
- 人生：校园或职场通行证、等级进度、连接的里程碑。保持每条新记录 +20 XP、每 100 XP 升级规则。
- 毛圈：带胶带的纸张动态，支持全部/有照片筛选。显示“本机毛圈”和设备可见范围。
- 手账：个人照片纸框、居民资料、实际记录统计、照片时间轴。数据与备份默认折叠。
- 登记：居民证实时预览；手机使用紧凑预览。名字、类型、年龄、性格、人生路线使用编号标签。
- 记录（宠语翻译机）：上方气泡是主人原话，下方气泡实时显示宠物版本并可直接改字；其后依次是口吻选择、“让 AI 来说”与本周剩余次数、标签、照片、发布范围、保存。
- 街区首页的主角卡按时段换底色，并用气泡展示宠物最近说的一句话。

## 文案规则

标题说明当前内容，按钮说明操作。删除重复产品介绍、感情口号、未来功能说明。保留本机数据范围、生成方式（本机生成 / AI 生成）、娱乐报道标识、上传限制和清空/删除/恢复确认。

## 响应式与交互

手机底部为悬浮的四个图标导航，中央是记录按钮；桌面为深色侧栏。宽屏首页和人生采用两栏；手机按内容顺序排列。长名字在顶部截断，档案正文换行。历史记录使用保存时的宠物快照。

新增装饰采用 React Native View 与样式，无额外图片网络请求。地图入口分别前往手账、人生和毛圈。照片、导出、备份恢复、数据清空沿用现有业务逻辑。
