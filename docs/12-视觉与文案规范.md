# 视觉与文案规范

版本：2026-10-11，适用于 Web 与移动端共享页面。

## 视觉方向

以“生活街区 + 纸质手账”组织页面。奶油底色搭配深墨色、珊瑚橙、玉绿色、紫色与暖黄色。页面按照内容使用不同形状：照片纸框、身份票证、报纸头版、公告墙和时间轴。

基础色：背景 #F4F0E7；文字 #242B29；操作 #EE6D4E；职场 #247563；校园 #7565CC；主角卡 #F5CC65。统一 token 保存在 src/components/ui.tsx。图标沿用 Feather，Web 使用内嵌 SVG。

## 页面布局

- 街区：宠物主角卡、三个可点击建筑、成长存折、个人喵闻、最近记录。展示真实本机记录数量和经验。
- 人生：校园或职场通行证、等级进度、连接的里程碑。保持每条新记录 +20 XP、每 100 XP 升级规则。
- 毛圈：带胶带的纸张动态，支持全部/有照片筛选。显示“本机毛圈”和设备可见范围。
- 手账：个人照片纸框、居民资料、实际记录统计、照片时间轴。数据与备份默认折叠。
- 登记：居民证实时预览；手机使用紧凑预览。名字、类型、年龄、性格、人生路线使用编号标签。
- 记录：真实日常、照片、口吻编辑、发布范围按任务顺序展示。

## 文案规则

标题说明当前内容，按钮说明操作。删除重复产品介绍、感情口号、未来功能说明。保留本机数据范围、模板来源、娱乐报道标识、上传限制和清空/删除/恢复确认。

## 响应式与交互

手机底部四个图标导航，桌面深色侧栏。宽屏首页和人生采用两栏；手机按内容顺序排列。长名字在顶部截断，档案正文换行。历史记录使用保存时的宠物快照。

新增装饰采用 React Native View 与样式，无额外图片网络请求。地图入口分别前往手账、人生和毛圈。照片、导出、备份恢复、数据清空沿用现有业务逻辑。
