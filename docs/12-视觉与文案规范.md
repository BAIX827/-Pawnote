# 视觉与文案规范

版本：2026-10-26（视觉方向改为融合版），适用于 Web 与移动端共享页面。

## 视觉方向

2026-10-26 用户确认：**融合版**（docs/01 8.30）。在橘色波普的基础上，改成“大色块 + 大字 + 宠物照片当主角”，去掉荧光绿和粉色，男女都适合。样稿见项目文件夹 design/ui-改版方向-2026-10-25/pawnote-final.html。原橘色波普的说明、截图和组件代码完整存档在用户 Mac 的 pet/风格存档/原版橘色波普/。

要点：
- 保留：主橘色和米黄底；粗黑描边 2.5px（#111）和不模糊的硬投影；圆角 14px，胶囊标签和按钮全圆角；彩色胶带；倾斜贴纸式标签（-4° 到 6°）；黑底滚动条；黑边对话气泡；黑色圆角底部导航，中间记录按钮为橘色方块微倾斜。
- 硬投影默认 3px 3px 0 #111（原 4px），色块本身可以不加边框，黑边和投影优先用在按钮、贴纸、卡片这些能点或像“贴上去”的东西上。
- 宠物照片贴纸：有照片时用白边贴纸（粗白边、黑色硬投影、倾斜、顶上胶带），用于爪窝主角卡、头像、相框；没照片时用物种头像，底色为浅橘。自动抠图贴纸是下一步（8.30 第 7 条）。
- 超大标题字：宠物名、页面标题、关键数字用特大字号；正文保持清晰的黑体。
- 底部导航选中项、主要按钮、滚动条文字用黄油黄（原荧光绿）。
- 不再使用：荧光绿、粉色、水彩晕染、柔和大投影、奶油渐变。

基础色（统一 token 在 src/components/ui.tsx，token 名沿用旧名，值已更新）：背景米黄 #FFF3DF；纸面 #FFFFFF；墨黑 #111111；主橘 #FF7A1A；黄油黄 #FFD84D（主要操作、选中态，token green / yellow）；钴蓝 #2B50FF（cobalt）；薄荷 #7FE0B5（mint，token sky 也指向它）；淡紫 #B9A6FF（lavender）；浅紫 #DDD2FF（lilac）；珊瑚 #FFB199（负向标记、危险操作，token pink）；浅橘 #FFE2C2（照片占位，token pale）；次要文字 #5C534A。职场路线用橘 + 黄油，校园路线用淡紫 + 薄荷。颜色不单独表达状态，负数同时带“−”号或文字。

字体（不变）：标题用站酷庆科黄油体（ZCOOL QingKe HuangYou），英文和数字用 Archivo Black，正文系统黑体。两者都是 SIL OFL 开源字体，随 App 打包，不从外网加载。标题字体做了子集化，界面新增汉字后需重新生成子集。图标沿用 Feather；爪印标志用代码绘制的橘色爪印（ui.tsx 的 PawMark），不用 emoji。

深色模式：当前版本只做浅色（app.json 固定浅色界面），深色模式以后单独排期。

## 页面布局

- 爪窝（首页）：橘色主角卡（滚动条、特大名字、头衔和性格贴纸、宠物照片贴纸）、“{名字}说”气泡、“它今天干了啥？”、本月小结三块数字（记录篇数、零食次数、拆家次数）、爪约、最近记录。展示真实本机记录数量和经验。
- 爪迹（成长）：校园或职场通行证、等级进度、连接的里程碑。保持每条新记录 +20 XP、每 100 XP 升级规则。
- 爪友圈（动态）：带胶带的纸张动态，支持全部/有照片筛选。显示“本机毛圈”和设备可见范围。
- 爪册（档案）：个人照片纸框、居民资料、实际记录统计、照片时间轴。数据与备份默认折叠。
- 登记：居民证实时预览；手机使用紧凑预览。名字、类型、年龄、性格、人生路线使用编号标签。
- 爪语（记录）：上方气泡是主人原话，下方气泡实时显示宠物版本并可直接改字；其后依次是口吻选择、“让 AI 来说”与本周剩余次数、标签、照片、发布范围、保存。
- 街区首页的主角卡按时段换底色，并用气泡展示宠物最近说的一句话。

- 月度考核：票据样式的工资条或成绩单，下接绩效等级印章、考核报告；顶部可切换月份。
- 时光机：纪念日数字卡、按月排开的拍立得、“第一次”清单。

- 爪报：日报、号外、通缉令、封面四个版式，顶部切换；难过的记录只有朴素记录卡。
- 爪约：到点提醒卡放在爪窝主角卡下方，粉色底、黑边对话气泡，宠物名小贴纸 + 它说的话 + 活动和时间，按钮“陪了”（荧光绿）与“晚点”（白）；完成后变成“记进爪语”。爪约页为约定列表（每条一张白卡：活动名、时间大数字、星期胶囊、开关、宠物会说的话预览）、按物种的预设贴纸（一点即加）、自定义输入区（事情、时间、星期）。网页版在页内说明只在打开爪窝时提醒。

## 文案规则

标题说明当前内容，按钮说明操作。删除重复产品介绍、感情口号、未来功能说明。保留本机数据范围、生成方式（本机生成 / AI 生成）、娱乐报道标识、上传限制和清空/删除/恢复确认。

## 响应式与交互

手机底部为悬浮的四个图标导航，中央是记录按钮；桌面为深色侧栏。宽屏首页和人生采用两栏；手机按内容顺序排列。长名字在顶部截断，档案正文换行。历史记录使用保存时的宠物快照。

新增装饰采用 React Native View 与样式，无额外图片网络请求。地图入口分别前往手账、人生和毛圈。照片、导出、备份恢复、数据清空沿用现有业务逻辑。
