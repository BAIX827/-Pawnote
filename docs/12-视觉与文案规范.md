# 视觉与文案规范

版本：2026-10-11，适用于 Web 与移动端共享页面。

## 视觉方向

2026-10-11 用户确认：**橘色波普**（新粗野主义），替换此前的水彩绘本风，并作为长期风格保持，除非用户另行说明。样稿见 docs/reference/风格提案-2026-10-11.html 的“方向 2 橘色波普”（爪窝首页、月度工资条）。

要点：
- 粗黑描边 2.5px（#111），硬投影 4px 4px 0 #111（不模糊），圆角 14px；胶囊标签和按钮为全圆角。
- 撞色色块代替柔和渐变。橘色是主角色（橘总本身就是橘猫），首页主角卡整块橘色，大字名字压在色块上，照片带黑边嵌在一角。
- 超大标题字：宠物名、页面标题、实发金额等关键数字用特大字号制造节奏；正文保持清晰的黑体。
- 点缀：倾斜的贴纸式标签（-4° 到 6°）、黑底荧光字滚动条（如“今日主角 ★ ORANGE BOSS ★”，减少动态效果时静止）、对话气泡带黑边尖角、绩效等级用倾斜色块盖章。
- 底部导航为黑色圆角条，选中项荧光绿，中间记录按钮为橘色方块微倾斜。
- 不再使用：水彩晕染、柔和大投影、奶油渐变、虚线圆形印章。

基础色：背景 #FFF3DF；纸面 #FFFFFF；墨黑（文字、描边、投影）#111111；主橘 #FF7A1A；荧光绿 #C6F432（主要操作、选中态）；淡紫 #B9A6FF；粉 #FF9EC7（扣款、提醒等负向标记）；次要文字 #5C534A。职场路线用橘 + 荧光绿，校园路线用淡紫 + 粉。颜色不单独表达状态，负数同时带“−”号或文字。统一 token 保存在 src/components/ui.tsx。

字体：标题用站酷庆科黄油体（ZCOOL QingKe HuangYou），英文和数字用 Archivo Black，两者都是 OFL 开源字体，打包进 App（国内无法依赖 Google Fonts；中文标题字体体积过大时做子集化）。正文继续用系统黑体（iOS 为 PingFang SC）。图标沿用 Feather，线宽加粗。

深色模式：底色换 #17130F，描边和投影换 #FFF3DF，色块颜色保持不变。

## 页面布局

- 爪窝（首页）：宠物主角卡、三个可点击建筑、成长存折、个人喵闻、最近记录。展示真实本机记录数量和经验。
- 爪迹（成长）：校园或职场通行证、等级进度、连接的里程碑。保持每条新记录 +20 XP、每 100 XP 升级规则。
- 爪友圈（动态）：带胶带的纸张动态，支持全部/有照片筛选。显示“本机毛圈”和设备可见范围。
- 爪册（档案）：个人照片纸框、居民资料、实际记录统计、照片时间轴。数据与备份默认折叠。
- 登记：居民证实时预览；手机使用紧凑预览。名字、类型、年龄、性格、人生路线使用编号标签。
- 爪语（记录）：上方气泡是主人原话，下方气泡实时显示宠物版本并可直接改字；其后依次是口吻选择、“让 AI 来说”与本周剩余次数、标签、照片、发布范围、保存。
- 街区首页的主角卡按时段换底色，并用气泡展示宠物最近说的一句话。

- 月度考核：票据样式的工资条或成绩单，下接绩效等级印章、考核报告；顶部可切换月份。
- 时光机：纪念日数字卡、按月排开的拍立得、“第一次”清单。

- 爪报：日报、号外、通缉令、封面四个版式，顶部切换；难过的记录只有朴素记录卡。

## 文案规则

标题说明当前内容，按钮说明操作。删除重复产品介绍、感情口号、未来功能说明。保留本机数据范围、生成方式（本机生成 / AI 生成）、娱乐报道标识、上传限制和清空/删除/恢复确认。

## 响应式与交互

手机底部为悬浮的四个图标导航，中央是记录按钮；桌面为深色侧栏。宽屏首页和人生采用两栏；手机按内容顺序排列。长名字在顶部截断，档案正文换行。历史记录使用保存时的宠物快照。

新增装饰采用 React Native View 与样式，无额外图片网络请求。地图入口分别前往手账、人生和毛圈。照片、导出、备份恢复、数据清空沿用现有业务逻辑。
