## 版本含义
- v0.1：可交互的本地数据原型，Web 优先预览，同一 Expo 工程保留移动端入口。
- v0.2：接真实账号、数据库、图片存储和服务端生成；开始 iOS / Android 真机开发构建。
- v0.3：熟人毛圈、审核和删除链路，封闭测试。
- v1.0：完成移动平台验收及发布准备后的手机 MVP。

Web 原型的完成与手机 MVP 的完成分别验收。每次功能变更更新需求、任务与交付状态；产品规则改变时追加决策记录。文档中“已实现”必须有对应代码或验证证据。
