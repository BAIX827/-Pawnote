# 爪记原版风格存档：橘色波普

存档日期：2026-10-26
来源：GitHub `BAIX827/-Pawnote` main 分支，提交 `e4a7189`
用途：爪记以后要换成新界面。这里留一份原来的风格，以后想用回来、或者在别的项目里用，都可以从这里拿。

## 风格一句话

新粗野主义的波普风：米黄色底，配撞色色块（亮橙、荧光绿、淡紫），所有卡片都有 2.5px 粗黑描边和不模糊的黑色偏移投影，大字标题用站酷庆科黄油体。

## 颜色

| 用途 | 色值 |
|---|---|
| 页面背景 | `#FFF3DF` |
| 纸面 / 卡片 | `#FFFFFF` |
| 墨黑（文字、描边、投影） | `#111111` |
| 主橘 | `#FF7A1A` |
| 荧光绿（主要操作、选中态） | `#C6F432` |
| 淡紫 | `#B9A6FF` |
| 浅紫 | `#DDD2FF` |
| 粉（扣款、提醒等负向标记） | `#FF9EC7` |
| 淡粉 | `#FFD3E5` |
| 红 | `#E0483A` |
| 次要文字 | `#5C534A` |

人生路线配色：职场路线用橘配荧光绿，校园路线用淡紫配粉。

## 字体

- 标题：站酷庆科黄油体（ZCOOL QingKe HuangYou），已子集化，约 2MB
- 英文和数字：Archivo Black
- 正文：系统黑体（iOS 上是苹方）
- 两种字体都是 SIL OFL 开源许可，可以免费商用，文件和许可证在 `字体/` 里

## 形状和组件

- 卡片：白底，圆角 14，2.5px 黑边，投影 `4px 4px 0 #111`
- 胶囊标签和按钮：全圆角
- 贴纸式标签：倾斜 -4° 到 6°
- 对话气泡：黑边，带尖角
- 黑底荧光字滚动条，比如“今日主角 ★ ORANGE BOSS ★”
- 绩效等级用倾斜色块，像盖章
- 爪友圈动态：纸张卡片，顶部贴彩色胶带
- 底部导航：黑色圆角条，选中项荧光绿，中间的“记录”按钮是橘色方块，微微倾斜
- 爪印标志：代码画的橘色爪印（`ui.tsx` 里的 `PawMark`），不用 emoji

## 文件夹里有什么

- `截图/`：2026-10-14 第三轮试用时的真实界面截图，包括首页、日记、爪友圈、爪册、爪约、桌面版、英文版
- `代码/ui.tsx`：全部颜色、字体、阴影 token 和通用组件（按钮、卡片、标签、气泡等），想复用的话直接从这里拿
- `代码/Shell.tsx`：外框和底部导航
- `代码/Icon*.tsx`、`代码/fonts*.ts`：图标和字体加载
- `字体/`：两套字体文件和许可证
- `视觉与文案规范-原文.md`：仓库 docs/12 的完整原文，包含每一页的布局说明
- `风格提案-2026-10-11.html`：当初选中这套风格时的样稿（方向 2 橘色波普），用浏览器打开就能看
